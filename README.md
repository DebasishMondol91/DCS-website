DCS website

Open index.html in any browser. Everything (CSS, JS, logos) is inside that one file.
Enquiry form: saves each submission to the Supabase project "DCS-website" (table: enquiries).
This only works when the page is hosted on a normal website (Netlify, GitHub Pages, your own hosting).
View enquiries in Supabase > Table Editor > enquiries.
supabase-setup.sql shows the table and security rules already created.
